# Runtime files that still log a way that is invisible or unfilterable, and
# predate the ban (notes/logging/README.md § "Legacy logging is banned",
# enforced by scripts/check-logging-legacy.mjs).
#
# What counts, and what each one costs:
#   - `.debug()` on any receiver outside lib/logging/. Depending on the receiver
#     this is either DARK (a pino child of the `info` root — never written) or
#     topic-gated SDK PROSE (no `event` field). The call site does not say
#     which, which is the point. Replacement: `getDebugEmitter(component, topic)`.
#   - `logDebug(...)` / `log(...)` prose through the Homey SDK.
#   - a computed log level (`logger[level](…)`), which can resolve to a dark debug.
#   - `console.*`, which bypasses the Homey destination entirely.
#
# Format: "<path> <site count>". The count is a budget and may only SHRINK.
# Both drift directions fail the guard: a higher count means new legacy logging
# landed in a file that is supposed to be shedding it, and a lower one means the
# line was not updated after a migration. So this list cannot rot into a
# permanent exemption. When the last line goes, DELETE THIS FILE — the guard
# then requires its absence.
#
# Counts were 63 files / 122 sites at the guard's introduction; 50 files / 80 sites now.
# The executor lane is gone: its debug events were the four *_command_skipped that
# production never showed, and they now resolve their own emitter.
