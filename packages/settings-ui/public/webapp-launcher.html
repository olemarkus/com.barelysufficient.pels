    Code for a phone

    Scan this code with your phone's camera. It opens the web app on the phone, ready to add the Homeys listed here.

    The code holds these Homeys' API keys. Each key can read and change the settings of every app on its Homey. Show the code only to your own phone.

    Add a Homey

    Name Shown when you switch between Homeys, for example House or Cabin.
    Homey address Paste the address PELS shows under Settings → Open in a browser, or the address of this Homey's page in the Homey web app.
    API key Create one in the Homey web app → Settings → API Keys, with permission to control apps: open the Homey web app. The key can read and change the settings of every app on this Homey. It is kept only in the browsers you add it to, never sent to the PELS website; delete it in Homey to disconnect. On a phone, the Homey web app needs Chrome's Desktop site option for API Keys. It is easier to add the Homey on a computer and choose Show code for a phone there.
